# Deviations and implementation notes

Prereg: `docs/preregistration.md`, sha256 `3910d3f3278ac0f93aa609ff939666e3b2ebc2c9a43636dc720e43305b74a1c5`, sealed 2026-10-08 20:30:27 HST.

1. **Re-execution after an out-of-memory kill (exploratory step only).** The first execution printed all four primary results (P1–P4: T*, AUC_B at T* and identity, Δ, CI, verdict) and was then killed by the OS while converting the 16182 × 26239 IR PNG to float64 for the exploratory IR AUC. Its log is kept unchanged as `run1-oom-killed.log` (sha256 `6b06de1754c8dd3894c9a7887972d38cf3f7e97e5977aa50fb405e0ae613436b`). The only code change was the IR luminance step, which now runs in 1024-row bands in float32. The primary computation is deterministic and unchanged. The full re-execution (`run.log`) printed P1–P4 lines that are byte-identical to the first run (checked with `diff` for each line). No primary number was chosen between runs.
2. **Luminance rounding (implementation detail).** The prereg defines luminance as 0.299R + 0.587G + 0.114B. It is rounded to the nearest integer (`np.rint`) per level-0 pixel and stored as uint8 before the 2 × 2 pooling, so the IR map uses the same 0..1020 histogram path as the predictions. This affects only the exploratory IR AUC.
3. **Context note on the question's motivating number.** The prereg's motivation quotes our selector study's best 500p2a arm (0.5246). That study used the published level 1, which we later found contains only level-0 planes 0–32 (see the selector study's deviations item 4). The motivation number therefore describes ink_9um on a partial input. This study does not use ink_9um predictions, so its verdict is unaffected.
