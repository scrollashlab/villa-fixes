# Security policy

## Reporting a vulnerability

Please report security issues privately, in either of these ways:

- GitHub's private reporting: open the **Security** tab and choose **Report a vulnerability**, or go directly to https://github.com/scrollashlab/villa-fixes/security/advisories/new
- Email: scrollash.lab@gmail.com

Please do not open a public issue for a vulnerability.

## Scope

This repository contains code, patches and scripts only. It runs no hosted services, so reports should concern the code itself, for example a script or patch that could be unsafe to run.
